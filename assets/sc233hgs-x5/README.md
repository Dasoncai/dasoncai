# SC233HGS / RDK X5 素材目录

当前已加入 cover-verified-1320x800.webp 产品示意封面，参数来自作者确认。尚无实拍图、运行日志或采集文件；请将真实素材放入本目录后，再更新文章信息中的对应字段。未引用的文件不会发布到网站。

建议文件名：

- module-front.webp / module-back.webp：模组正反面。
- board-connection.webp / connector-closeup.webp：实际连接与接口局部。
- test-scene.webp：测试场景。
- raw-preview.webp：注明转换设置的 RAW 预览图。
- yuv-preview.webp：注明格式与转换设置的 YUV 预览图。
- iq-before.webp / iq-after.webp：同场景 IQ 前后对比。
- preview.mp4：实际采集或检测演示。
- deployment.log / capture.log / isp.log：驱动部署、RAW 和 ISP 运行日志。
- metrics.csv：真实测量数据，表头 variant,metric,value,unit,samples。

RAW/YUV 大文件可放到外部存储，再在文章中填写 HTTPS 下载链接。务必注明宽高、位深/格式、packing、stride/plane 和转换方法。

请勿把本目录说明或预期指标当成已完成验证。上传素材后按 AUTHORING.md 更新 Markdown；接入方式和模组彩色/黑白版本需据实确认。
